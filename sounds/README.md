# 効果音のファイル

このフォルダに、**効果音ラボ**（https://soundeffect-lab.info/sound/anime/ ）の効果音を入れます。
サイトで音を聞いてダウンロードし、**ファイル名を変えずに**（日本語の名前のまま）このフォルダへ入れてください。
どの場面でどのファイルを鳴らすかは `js/config.js` の `SOUNDS` に書いてあります。
音を差し替えるときは、新しいファイルをここに入れて、`SOUNDS` のファイル名を書き換えます。

| 場面 | ファイル名（ダウンロードしたときの名前） |
|---|---|
| ゲーム開始 | 和太鼓でドドン.mp3 |
| ターンの結果公開（音の大きさの試し聞きにも使う） | ジャン！.mp3 |
| 自分がバースト | チーン1.mp3 |
| 重複して +0 | ショック1.mp3 |
| 時間切れ・無効で +0 | 間抜け3.mp3 |
| ぴったり賞 | レベルアップ.mp3 |
| 最終結果の前 | ドラムロール.mp3 |
| ドラムロールの締め | ロールの締め.mp3 |
| 勝者 | ラッパのファンファーレ.mp3 |
| 勝者・観戦者 | 歓声と拍手1.mp3 |
| 負け・勝者なし | ちゃんちゃん♪2.mp3 |

ファイルが見つからない音は、鳴らないだけです（ゲームは止まりません）。
ブラウザの開発者ツールのコンソールに「効果音「〜」を読み込めませんでした」と出るので、名前を確かめてください。

## 利用規約で気をつけること（2026年11月に確認）

- 無料・商用可・クレジット表記は任意。アプリへの組み込みは「音源ファイルむき出しでも可」。
- **禁止**：効果音を自由に鳴らせるアプリにすること、ファイルへの直リンク、ファイルの再配布。
  → このゲームでは、決まった場面と、音の大きさの試し聞きでだけ鳴らしています。音を自由に試聴できるページは作らないでください。
- 規約は変わることがあるので、公開前にもう一度サイトで確認してください。
